# CLAUDE.md

## Communication

### Spell out acronyms and jargon

When using an acronym or industry term, write the acronym first and follow it
with the plain-English meaning in parentheses:

```
LTV (Lifetime Value)
CTR (Click-Through Rate)
LPV (Landing Page View)
```

Do this on the **first use in each response**, including inside tables, chart
labels, and column headers. After the first expansion in that response, the
bare acronym is fine.

This applies to marketing, advertising, and analytics vocabulary generally —
not just metric abbreviations. Platform and settings jargon counts too:

- CBO (Campaign Budget Optimization)
- ABO (Ad Set Budget Optimization)
- Audience Network (Meta's network of third-party apps and websites outside
  Facebook and Instagram)

If a term has no common acronym but is still jargon, give a short plain
definition on first use rather than assuming it is familiar.

Common ones in this account's work:

|---|---|
| CTR | Click-Through Rate |
| CPC | Cost Per Click |
| CPM | Cost Per Mille (cost per 1,000 impressions) |
| LPV | Landing Page View |
| LTV | Lifetime Value |
| ROAS | Return On Ad Spend |
| CPA | Cost Per Acquisition |
| CPL | Cost Per Lead |
| AOV | Average Order Value |
