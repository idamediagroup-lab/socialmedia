# Score Machine Masterclass — Deck Build

**Score-Machine-Masterclass.pptx** — 87 slides, 16:9 widescreen.

## Importing into Canva
Canva → Create a design → Import file → select the .pptx. Text, charts and
layout come in editable. Backgrounds arrive as two slide masters.

## Swapping in the real background
`bg_light.jpg` / `bg_dark.jpg` are recreations of the brand background art.
To use the original file: in Canva, replace the two master backgrounds; or drop
the real PNGs in here as `bg_light.jpg` / `bg_dark.jpg` and re-run `node gen.js`.

## Files
| File | What it is |
|---|---|
| `gen.js` | Deck generator — edit copy here and rebuild |
| `bg.py` | Draws the two background variants |
| `preview.py` | Renders approximate slide previews (LibreOffice is unavailable in this env) |

## Rebuild
```
node gen.js
```
